# ADB Desk · 应用图标规格

## 1. 概念

**外壳就是设备，里面是命令。**

图标只有两层：一块石墨色超椭圆底板，加一行终端提示符 `>` 与插入光标 `▍`。
没有机身轮廓 —— 不画手机，也不画车机。因为 ADB 面对的是「任意一台 Android 设备」，
一旦画出具体形态，就把工具的使用范围说小了。设备形态交给应用界面去表达，
图标只承诺一件事：连上就能下命令。

这个决定也让图标只有一个版本：16 到 1024px 用同一份图形，不需要小尺寸特调稿，
任务栏、标题栏、安装器、Dock 的观感完全一致。

## 2. 文件清单

| 路径 | 用途 |
| --- | --- |
| `design/icon/icon.svg` | 唯一源文件（1024 网格，可直接用于 Web / 文档 / 应用内） |
| `design/icon/png/icon-{16…1024}.png` | 11 档透明底光栅，供文档、商店页、README 使用 |
| `design/icon/icon.ico` | Windows 多尺寸图标（16/20/24/32/40/48/64/128/256） |
| `design/icon/icon.icns` | macOS 图标（16/32/64/128/256/512/1024） |
| `design/icon/icon-board.html` | 展示板：尺寸阶梯、场景、构造、禁忌 |
| `design/icon/tools/` | 生成与导出脚本，改稿后可一条命令重出全套 |

已接入打包链路（覆盖 electron-vite 模板自带图标）：

- `build/icon.ico` → Windows 可执行文件与 NSIS 安装器
- `build/icon.icns` → macOS 应用包
- `build/icon.png`（1024）→ Linux 打包
- `resources/icon.png`（512）→ 主进程 `BrowserWindow` 的 Linux 窗口图标

## 3. 构图参数

画布 1024×1024，坐标原点左上。

| 元素 | 参数 |
| --- | --- |
| 底板 | 超椭圆（指数 n=5.0），中心 (512,512)，半径 428；四周安全边 84 |
| 内描边 | 同形收缩 1.6px，`#FFFFFF` 13%，3px |
| 提示符 | 折线 `M366 344 → L506 512 → L366 680`，描边 104，圆头圆角 |
| 光标 | 矩形 96×252，圆角 30，位于 x=600，垂直中心 524 |
| 图形占幅 | 368×440（画布宽 36%、高 43%），双轴居中 |
| 光学对齐 | 折线外沿 x=328 与光标右沿 x=696 关于 512 对称 |

文字基线没有参与对齐：光标按光学中心（而非基线）与折线配平，是因为在 1024 的
大尺度下，基线对齐会让右侧显得重心偏低。

## 4. 颜色

| 令牌 | 值 | 说明 |
| --- | --- | --- |
| 底板渐变 | `#2B3343` → `#161A23` → `#0A0C11` | 145° 斜向；止色与深色主题 `--console-bg` 同源 |
| 左上高光 | `#FFFFFF` 16% → 0 | 径向，模拟单一光源 |
| 底部辉光 | `#3555FF` 30% → 0 | 与界面强调色同色，压住下缘 |
| 提示符 | `#FFFFFF` | 纯白，16px 下仍是唯一强对照元素 |
| 光标 | `#2B49F5` | 比 `#3555FF` 略深，在深底上更实 |

对比度：白色提示符 / 底板 ≈ 15:1；蓝色光标 / 底板 ≈ 3.6:1（作为图形元素，
满足 WCAG 1.4.11 非文本对比 ≥3:1）。

## 5. 使用规则

1. 只做等比缩放，不拉伸、不加投影、不改色相、不降透明度。
2. 不叠加文字或 badge。要表达「已连接」用界面内的状态点，不要改图标。
3. 浅色背景直接使用，不需要另做深色稿 —— 底板自带对比。
4. 小于 16px 不要使用；需要更小请改用应用内的文字标识。

## 6. 重新生成

```bash
cd design/icon/tools
python gen.py                                   # 出 icon.svg
node render.mjs icon                            # 光栅化 11 档
python export.py                                # 打包 png/ + .ico + .icns
```

改几何只需动 `gen.py` 顶部的坐标常量，`export.py` 会自动按尺寸取图。

## 7. 已知边界

- macOS 官方网格是 824/1024，本稿为 856/1024。若上架 Mac App Store 且被审核挑出，
  把 `gen.py` 的 `TILE_A` 改为 412 重出即可，其余参数不用动。
- Windows 缩略图/预览缓存较顽固，替换后如仍看到旧图标，重启资源管理器或清
  `%LOCALAPPDATA%\IconCache.db`。
