# ADB Desk 界面设计方案 v1.0

> 交付物：`design/prototype.html`（高保真可交互原型，浅色 + 深色）
> 适用范围：`ADB-desk-app` 渲染层（Electron + React 19 + TypeScript，Vite）
> 设计基准：1180 × 800 窗口，最小 960 × 620

---

## 1. 设计定位

**一句话**：把「记 adb 命令、拼参数、切终端」的重复劳动，收敛成一个随时能看到设备状态、命令与结果同屏的工作台。

**目标用户**：Android 开发 / 测试 / 逆向排查人员。特征：每天高频重复同类操作，桌面端长时间驻留，键盘熟练，但对 adb 参数细节不一定记得住。

**三条设计原则**

| 原则 | 落地方式 |
| --- | --- |
| 设备优先 | 当前设备常驻侧栏一级位置，所有命令、截图动作都显式标注目标序列号；离线设备直接禁用操作，而不是执行后报错 |
| 输出即上下文 | 命令编辑与结果输出同一屏，运行状态、耗时、退出码常驻可见；回到概览仍能看到「最近运行」 |
| 键盘优先、鼠标可达 | `Ctrl+K` 全局搜索、`Ctrl+↵` 运行、`Esc` 关闭、`↑↓` 选择；所有控件保留 ≥ 24×24 命中区与可见焦点 |

**相比当前实现的关键变化**

1. 新增「概览」页，把设备状态、快捷操作、最近截图、常用命令、最近运行聚合为首页。
2. 设备切换从「隐式」变为「显式」：侧栏常驻切换器，切换即改变全局目标设备。
3. 命令库、编辑器、控制台三区同屏，运行状态可视化（运行中 / 完成 / 中断）并有停止入口。
4. 截图页采用「左列表 + 右大图」结构，预览不再溢出信息栏。
5. 危险操作（重启设备）引入二次确认；空 / 离线 / 运行中状态成体系。

## 2. 信息架构

```
ADB Desk
├─ 设备切换器（所有页共享的上下文）
├─ 概览        设备状态 · 快捷操作 · 最近截图 · 常用命令 · 最近运行
├─ 命令台      命令库（搜索/收藏）· 命令详情（名称/模式/命令）· 输出控制台
├─ 截图        截图列表 · 预览 · 在文件夹中显示 / 删除
└─ 设置        adb 环境 · 截图存储 · 外观 · 快捷键
```

**核心任务流**

1. 连设备 → 概览确认在线 → 点快捷操作 → 跳到命令台看输出。
2. 选命令 → 改参数 → `Ctrl+↵` 运行 → 看流式输出 → 停止或复制。
3. 截图 → 在右侧大图核对 → 定位文件 / 删除。
4. adb 不可用 → 概览顶部与设置页同时提示 → 指定 adb 路径 → 重新检测。

**与现有 IPC 的对齐**

| 界面能力 | 现有 API |
| --- | --- |
| 设备列表 / 在线状态 | `adb.devices()` |
| adb 版本与路径 | `status()`、`settings.pickAdbPath()`、`settings.update()` |
| 命令库增删改、收藏 | `commands.list / save / remove / toggleFavorite` |
| 运行、流式输出、停止 | `commands.run / onOutput / onDone / kill` |
| 截图、删除、定位 | `shots.list / capture / remove / reveal`、`settings.openShotsFolder()` |
| 主题 | `settings.update({ theme })` |

「最近运行」为前端内存态（最近一次 `run` 的命令与输出摘要），不需要改 IPC 协议。

### 4.2 字体

| 角色 | 规格 |
| --- | --- |
| 字体族 | `Inter, -apple-system, "Segoe UI", "Microsoft YaHei", sans-serif` |
| 等宽 | `ui-monospace, SFMono-Regular, Menlo, Consolas, monospace` |
| 正文 | 13px / 1.55 / 400 |
| 控件文本 | 12.5px |
| 辅助说明 | 11.5px |
| 微型标签 / 计数 | 10.5px（导航分组 10px，字距 .09em，全大写） |
| 页标题 | 14.5px / 600（顶栏） |

### 4.3 间距与形状

- 间距：2px 基准，主步进 4/6/8/10/12/14/16/18/20。
- 圆角：标签 5–6、控件 7–8、卡片/面板 10、面板容器 12、大卡/浮层 14。
- 描边统一 1px；只有浮层（下拉、命令面板、对话框）用阴影，卡片不使用重投影。
- 阴影：`0 1px 2px rgba(16,24,40,.04)`（卡片）；`0 1px 2px + 0 14px 34px -10px rgba(16,24,40,.22)`（浮层）。

### 4.4 动效

| 场景 | 时长 / 曲线 |
| --- | --- |
| 控件悬停、选中 | 120ms ease |
| 浮层进入 | 160ms，位移 6px + 透明度 |
| 运行状态点 | 1.3s 呼吸 |
| 控制台新行 | 160ms 淡入上移 2px |

`prefers-reduced-motion: reduce` 时全部关闭，命令输出改为一次性渲染。

## 6. 页面规格

### 6.1 概览

- **设备卡**：设备图标 + 型号 21px + 序列号（等宽）+ Android / ABI + 在线 / 连接方式 / SDK 徽标；右侧「刷新」「截图」。
- **快捷操作**：2 行 × 3 列，每项含图标、名称、等宽命令预览；点击跳到命令台并自动运行（截图直接抓屏）。离线时整组禁用。
- **两栏**：最近截图（3 张，点击进截图页并选中）、常用命令（收藏前 5 条，点击载入）。
- **最近运行**：最近一条命令 + 输出前 4 行 + 退出码 / 耗时，右侧直达命令台。
- 纵向不产生页面滚动（1180×800 实测 613px / 可用 618px）。

### 6.2 命令台

- **左栏**：命令库计数、搜索（名称与命令全文）、按收藏优先排序、模式徽标；底部显示过滤结果数与 `↑↓` 提示。
- **编辑区**：名称、`shell | adb` 分段、目标设备（只读，随全局设备变化）、等宽命令输入、模式说明；底部「保存」「运行」，左侧快捷键提示。
- **控制台**：首行回显完整 `adb` 调用，运行中显示呼吸点 + 实时耗时，结束后显示退出码与总耗时；支持清空、复制、停止。
- **状态机**：就绪 → 运行中（禁用运行、启用停止）→ 完成（绿点）/ 失败（红点，展示 stderr）/ 中断（`^C`，退出码 130）。
- **空命令**：运行前校验并轻提示，不产生空回显。

### 6.3 截图

- 左栏 2 列缩略图，显示时间与体积；悬停出删除；键盘 `Enter/Space` 选中。
- 右侧预览：点阵背景衬托设备画面，`inset 18px` 内等比缩放，任何窗口尺寸都不与头尾信息栏重叠。
- 底部信息：分辨率、体积、完整时间、格式。
- 头部操作：打开目录、截图（截图中禁用并显示「截图中…」）；预览操作：在文件夹中显示、删除。
- 空状态：引导点击「截图」。无选中时自动回落到第一张。

### 6.4 设置

- 分组卡片：adb 环境 / 截图存储 / 外观 / 快捷键；每组「标题 + 一行说明」。
- 行结构：左侧标题 + 说明，右侧控件；路径用等宽文本 + 省略号 + `title` 悬浮完整值。
- 主题切换与侧栏底部开关双向同步。
- 快捷键为只读展示（`Ctrl K`、`Ctrl ↵`、`Esc`）。

## 7. 交互规则

| 操作 | 反馈 |
| --- | --- |
| `Ctrl/Cmd + K` | 打开 / 关闭命令面板，输入框自动聚焦 |
| `Ctrl/Cmd + ↵` | 在命令台运行当前命令 |
| `↑ / ↓` | 命令面板内循环选择 |
| `Esc` | 依次关闭：对话框 → 命令面板 → 设备下拉 |
| 切换设备 | 更新侧栏、顶栏副标题、设备卡、编辑区目标；离线设备禁用运行与截图 |
| 运行命令 | 先回显命令行，再流式追加输出；stderr 红色；结束后写入「最近运行」 |
| 停止 | 输出 `^C`，退出码 130，状态「已中止」 |
| 删除截图 / 命令 | 立即删除并轻提示（截图仅删本地文件；命令可重新添加） |
| 重启设备 | 二次确认，默认焦点在「取消」，确认后运行 `adb reboot` |

## 8. 无障碍

- 颜色：正文 / 辅助文本 / 状态徽标 ≥ 4.5:1，已在第 4 节标注实测值。
- 焦点：统一 `2px accent` 外环、偏移 2px；输入框使用描边 + 3px 外环双层反馈。
- 键盘：全部交互可 Tab 到达；命令列表 `Enter/Space` 载入；缩略图可聚焦，删除按钮 `focus-within` 时可见。
- 语义：导航 `aria-current`，设备下拉 `role="listbox" / option`，控制台 `role="log" aria-live="polite"`，对话框 `aria-modal`，轻提示 `role="status"`。
- 命中区：图标按钮最小 26×26，主要操作 30 高，满足 WCAG 2.2 AA 的 24×24 最小目标。
- 动效：遵循 `prefers-reduced-motion`。

### 9.2 组件树

```
App
├─ Sidebar
│  ├─ Brand
│  ├─ DeviceSwitcher (adb.devices)
│  ├─ Nav (概览 / 命令台 / 截图 / 设置)
│  └─ ThemeSwitch + adb 状态
├─ Topbar (标题 / 副标题 / CommandPalette 触发器)
├─ OverviewPage (Hero, QuickActions, RecentShots, Favorites, LastRun)
├─ CommandsPage (CommandList, CommandEditor, ConsolePanel)
├─ ShotsPage (ShotGallery, ShotPreview)
├─ SettingsPage
└─ CommandPalette / ConfirmDialog / Toast
```

建议状态：`useDevices`、`useCommands`（含 run 流）、`useShots`、`useSettings`、`useTheme`；`Toast` 与 `Confirm` 用 Context 暴露 `toast()` / `askConfirm()`。

### 9.3 需要一并调整的地方

- 种子命令建议补两条：`最近任务 input keyevent 187`、`重启设备 reboot`（原型快捷操作已使用）。
- 「最近运行」保存在渲染进程内存即可；若要跨启动保留，再扩展 `Settings` 类型。
- 现有主题切换依赖 `settings.theme`，原型中的 `data-theme` 属性可直接映射。
- 设备离线时 `captureShot` / `run` 应在 UI 层拦截，避免抛出 IPC 错误。
